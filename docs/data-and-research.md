# Data and research

Public OSM base maps are attributed to OpenStreetMap contributors and use ordinary
viewport tiles. No tile scraping, prefetching or offline region downloads occur.
https://operations.osmfoundation.org/policies/tiles/
The LGA filter registry has the 23 names supplied in the project brief; no polygon
boundaries or automatic point-in-LGA validation are claimed.

Inspired by FixMyStreet's discoverable reports, public histories and follows:
https://fixmystreet.org/how-it-works/
https://fixmystreet.org/training/citizens/
CommunityConnect does not claim its authority routing or government delivery
integration. Updates here remain explicitly community-reported.

No reports, volunteer events, local opportunities, government statistics or
organization verification records were fabricated or imported as genuine data.
All public lists start with the actual approved database contents.
